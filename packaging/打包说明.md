# Mobilis 迁跃 打包说明 (Windows)

## 一键生成安装包

1. 安装 **Python 3.11 或 3.12 (64 位)**，安装时勾选 *Add python.exe to PATH*。
2. （可选，用于生成安装向导）安装 **Inno Setup 6**：https://jrsoftware.org/isdl.php
3. 双击 `packaging\build_windows.bat`，等待完成（首次 10–30 分钟，Nuitka 会自动下载 C 编译器）。

输出：

- `installer\Mobilis_Setup_1.16.0.exe` — 安装包：安装向导、开始菜单与桌面快捷方式（带图标）、卸载程序；
- `dist\Mobilis\Mobilis.exe` — 免安装版，整个 `dist\Mobilis` 文件夹可直接拷贝使用。

用户电脑上**不需要安装 Python**。

## 代码保护

`build_windows.bat` 使用 **Nuitka**：先把 Python 源码翻译成 C，再编译为机器码 (.exe / .pyd)。
发布目录和安装包中**不包含任何 .py / .pyc 源码**，脚本最后还会检查一遍。
要还原程序逻辑只能做二进制逆向，难度与逆向一般 C 程序相当，免费工具中这是保护效果最好的方案。

需要说明的是：任何在用户电脑上运行的程序都不可能做到“绝对无法破解”；Nuitka 的作用是让还原代码的成本远高于自己重写。
如需更强的保护，可以再加：

- 商业版 Nuitka (Nuitka Commercial) 的常量/字符串加密；
- 代码签名证书（防篡改，并减少杀毒软件误报）；
- 许可证授权（绑定机器码的激活机制），可在后续版本中加入。

`build_pyinstaller.bat` 是备选方案：构建快（几分钟），但 PyInstaller 只是把 .pyc 打包，可用现成工具提取并反编译，
**只适合自用或测试，不要用于对外分发**。

## 常见问题

- **杀毒软件报毒 / 拦截**：新编译、未签名的 exe 常被误报，可添加信任或使用代码签名证书。
- **编译报错找不到编译器**：Python 3.13 需先安装 *Visual Studio Build Tools (C++ 桌面开发)*；或改用 Python 3.11/3.12。
- **Nuitka 提示 `--windows-console-mode` 未知**：Nuitka 版本过旧，运行 `pip install -U nuitka`。
- **体积**：约 150–250 MB（numpy / scipy / matplotlib 占大部分），安装包压缩后约 60–90 MB。
- **重新生成图标**：修改 `tools_make_icon.py` 后运行 `python tools_make_icon.py`。
