# Mobilis 分步教程

每篇教程从安装好的程序出发，一步一步做完一个完整的计算。命令都在 `examples` 文件夹中运行
(`cd examples`)，所需的演示文件都在其中；换成自己的体系时只需替换文件名。

| 教程 | 内容 | 需要的外部程序 |
|---|---|---|
| [01 安装与第一次运行](01_安装与第一次运行.md) | pip / conda / Windows 安装包，检查安装，运行自带测试 | 无 |
| [02 晶体的电荷迁移率](02_晶体电荷迁移率.md) | CIF → 近邻二聚体 → EHT 转移积分 → TLT、KMC、方法对比、诊断 | 无 (精确计算用 Gaussian / ADF) |
| [03 重组能与量子核隧穿](03_重组能与量子核隧穿.md) | 四点法重组能、简正模式分解、费米黄金规则跳跃速率 | Gaussian |
| [04 激发态速率与 TADF](04_激发态速率与TADF.md) | TVCF：k_r、发射光谱、k_IC、k_ISC、k_RISC，S1/T1 动力学 | Gaussian (演示文件可直接运行) |
| [05 形变势能带迁移率](05_形变势能带迁移率.md) | 应变晶胞、弹性常数与形变势、Bardeen–Shockley 与玻尔兹曼输运 | 周期性 DFT (演示表格可直接运行) |
| [06 项目文件](06_项目文件.md) | 把整套设置保存为一个文件，检查并重新运行 | 无 |

所有命令都可用 `-h` 查看完整参数，例如 `python -m mobility_tool tvcf -h`。安装为 pip / conda 包后，
`python -m mobility_tool` 可简写为 `mobilis`，图形界面为 `mobilis-gui`。
