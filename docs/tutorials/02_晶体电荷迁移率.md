# 02 晶体的电荷迁移率

本教程用 `examples/pentacene.cif` (并五苯，室温结构)。全部步骤只用内置的 EHT 转移积分，几分钟内完成；
精确计算时，第 2 步换成 Gaussian / ADF 的二聚体计算即可，后面的步骤不变。

## 1. 近邻二聚体

```
python -m mobility_tool crystal pentacene.cif --cutoff 4.0 -o pen_dimers
```

按最短原子间距 4 Å 找出参考分子的全部近邻，按对称等价分组 (输出每组的质心距离与个数)，并在 `pen_dimers`
中写出每个独立二聚体的 Gaussian 输入。`--program adf` 写出 ADF 片段计算输入。

## 2. 转移积分

内置 EHT (秒级，适合筛选与趋势)：

```
python -m mobility_tool tlt pentacene.cif --carrier hole --temp 300
```

Gaussian 的投影法结果读取后用于迁移率：在 `pen_dimers` 中运行全部输入 (`python -m mobility_tool run pen_dimers`)，
然后 `python -m mobility_tool mobility --path pen_dimers --cif pentacene.cif --lam 0.098 --carrier hole`。

## 3. 选择输运模型

先让程序判断适用的模型 (耦合与重组能之比、动态无序、能量无序)，需要两种载流子的重组能：

```
python -m mobility_tool diagnose pentacene.cif --lam-h 0.098 --lam-e 0.132 --temp 300
```

并五苯 2|J|/λ 接近或大于 1，跳跃模型不适用，应以 TLT 为准。

## 4. TLT 与 KMC

```
python -m mobility_tool tlt pentacene.cif --carrier hole --temp 300 --sigma 0.3
python -m mobility_tool tlt pentacene.cif --carrier electron --temp 300 --sigma 0.3
python -m mobility_tool kmc pentacene.cif --lam 0.098 --carrier hole --temp 300
```

`--sigma` 是动态无序 σ_V/|J|；用 CEDS 曲面与 MD 得到的真实 σ_V 见用户手册的 `ceds` 一节。KMC 在晶体图上做
Marcus 跳跃，可加电场 (`--field`) 与能量无序 (`--sigma`)；`--rate fgr --modes …` 用全部振动模式的量子速率
(教程 03)。

## 5. 多种模型对比

```
python -m mobility_tool kmc-validate --cif pentacene.cif
```

KMC 对 12 个有精确解的情形自检。用户手册中 `compare` 一节说明如何把 TLT、各种 Marcus、Miller–Abrahams、GDM 与
能带模型放在同一张表中比较，并给出每个模型是否适用。
