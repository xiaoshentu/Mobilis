# 06 项目文件

一个项目文件 (`*.mobilis.json`) 保存一项研究的全部设置：变量 (文件名、温度、重组能……)、按顺序执行的计算步骤，
以及图形界面中各功能页的全部取值。它是纯文本，可以放进论文的补充材料或版本管理，别人用同一个文件即可重现结果。

## 1. 从模板新建

```
python -m mobility_tool project new pentacene.mobilis.json --template crystal --set cif=pentacene.cif
```

模板：`crystal` (晶体输运，EHT 耦合)、`emitter` (发光分子的 S1/T1 动力学)、`deformation` (形变势)。
用文本编辑器修改 `variables`，或增删 `steps` (每一步就是一条命令及其参数，`${名称}` 引用变量)。

## 2. 检查与查看

```
python -m mobility_tool project check pentacene.mobilis.json
python -m mobility_tool project show pentacene.mobilis.json
```

`check` 用真实的参数解析检查每一步 (不运行计算)，`show` 列出变量和每一步的状态。

## 3. 运行

```
python -m mobility_tool project run pentacene.mobilis.json
python -m mobility_tool project run pentacene.mobilis.json --only tlt_hole,kmc_hole
python -m mobility_tool project run pentacene.mobilis.json --start kmc_hole --set T=250
```

每一步的输出写入 `logs/<步骤名>.log`，状态 (返回码、用时、完成时间) 写入 `pentacene.status.json`。
`--set` 临时覆盖变量，`--keep-going` 在某一步失败后继续。

## 4. 图形界面

文件 → 保存项目 把当前结构和所有功能页的设置写入项目文件 (已有文件中的计算步骤保留)；文件 → 打开项目 恢复它们。
