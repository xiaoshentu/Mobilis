# 05 形变势能带迁移率

形变势理论 (Bardeen–Shockley) 给出声学声子散射限制的能带迁移率，需要周期性 DFT 计算应变晶胞的总能量与带边。

## 1. 生成应变晶胞

```
python -m mobility_tool dp-gen pentacene.cif --strains=-1,-0.5,0,0.5,1 --axes a,b --format poscar --out dp/pentacene
```

写出沿 a、b 的 10 个应变晶胞 (VASP POSCAR；`--format cif` 写 CIF) 和待填写的表格
`dp/pentacene_strain_table.csv`。

## 2. 周期性 DFT

对每个晶胞做单点或固定晶胞的原子优化，在表中填入每个晶胞的总能量 `energy_eV`、价带顶 `vbm_eV` 与导带底
`cbm_eV`。**带边必须以真空能级或芯能级为参考** (例如减去同一个深能级的能量)，否则形变势没有意义。

## 3. 拟合与迁移率

演示表格 (人工构造的数字) 可以直接运行：

```
python -m mobility_tool dp dp_demo/pentacene_strain_table.csv --cif pentacene.cif --mass 1.5 --temp 300 --out dp_results.csv
```

每个方向给出弹性常数 C (GPa)、形变势 E₁ (eV) 和三种迁移率：

- `μ_BS`：Bardeen–Shockley 公式，用 `--mass` 给定的有效质量；
- `μ_BS(TB m*)`：同一公式，有效质量取自 EHT 紧束缚能带在该方向的曲率；
- `μ_Boltzmann`：在完整的紧束缚能带上做玻尔兹曼输运，弛豫时间按形变势散射计算，不假设抛物带。

单层 (二维) 材料用 `--dim 2`，表中给 `area_A2`，C 的单位为 N/m。

## 4. 适用范围

有机分子晶体的带宽常与 k_BT 相近，此时能带图像本身可能失效 (程序会给出提示)，应与 TLT (教程 02) 对照。
