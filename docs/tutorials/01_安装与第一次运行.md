# 01 安装与第一次运行

## 1. 三种安装方式

**pip (Windows / macOS / Linux，需要 Python ≥ 3.9)**

```
pip install mobilis-1.31.0-py3-none-any.whl        # 发布的 wheel 文件
pip install "mobilis[fast]"                         # 发布到 PyPI 之后；[fast] 同时安装 numba (EHT 快几倍)
```

在源码文件夹中也可以 `pip install -e .`，修改代码后立即生效。

**conda**

```
conda env create -f environment.yml
conda activate mobilis
```

`packaging/conda/meta.yaml` 是 conda-build 配方 (`conda build packaging/conda`)，可以放到自己的 channel。

**Windows 安装包**：运行 `Mobilis_Setup_<版本>.exe`，不需要 Python，开始菜单中有图形界面的快捷方式。

## 2. 检查安装

```
python -m mobility_tool --version
python -m mobility_tool tvcf -h
```

第一条显示版本与开发者，第二条显示一个命令的全部参数。界面语言默认跟随系统，也可以指定：

```
python -m mobility_tool --lang en tlt -h
```

## 3. 第一次计算

在 `examples` 文件夹中对并五苯晶体做一次瞬态局域化 (TLT) 计算，转移积分由内置的扩展 Hückel (EHT) 方法得到，
不需要任何外部程序，几秒钟完成：

```
python -m mobility_tool tlt pentacene.cif --carrier hole --temp 300
```

输出中的 "μ 主值" 是 ab 平面内迁移率张量的两个主值 (cm² V⁻¹ s⁻¹)，"紧束缚带宽" 与 "有效质量" 来自同一组转移积分。

## 4. 图形界面

```
python -m mobility_tool gui
```

或 `mobilis-gui` (pip / conda 安装后)。文件 → 打开结构 读入 CIF，左侧各功能页对应本教程中的命令；
文件 → 保存项目 把全部设置写入一个项目文件 (见教程 06)。

## 5. 自带测试

```
python tests/run_all.py --quick
```

全部通过说明安装完整；不需要 Gaussian 或 ADF (用模拟程序代替)。
