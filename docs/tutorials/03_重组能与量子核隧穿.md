# 03 重组能与量子核隧穿

## 1. 四点法重组能

```
python -m mobility_tool reorg-gen benzene.xyz -o reorg --carrier both --method B3LYP --basis 6-31G(d)
```

在 `reorg` 中写出中性与离子态的优化 + 频率输入以及四个单点。用 Gaussian 运行 (本机：
`python -m mobility_tool run reorg`) 后：

```
python -m mobility_tool reorg-analyze reorg --json reorg.json
```

得到空穴与电子的 λ = λ₁ + λ₂。

## 2. 简正模式分解

用两个态的 freq fchk (`formchk benzene_neutral.chk`)：

```
python -m mobility_tool reorg-decomp reorg/benzene_neutral.fchk reorg/benzene_cation.fchk --csv benzene_hole
```

`benzene_hole_neutral_modes.csv` 与 `benzene_hole_ion_modes.csv` 列出每个模式的频率、黄昆因子 S 与 λ 贡献，
另有内坐标 (键长 / 键角 / 二面角) 与原子分解。

## 3. 量子核隧穿

Marcus 速率把全部振动当作经典处理；高频 C=C 伸缩 (约 1600 cm⁻¹) 在室温下是量子的。费米黄金规则速率用全部模式的
黄昆因子：

```
python -m mobility_tool tunneling --modes benzene_hole_neutral_modes.csv benzene_hole_ion_modes.csv --temps 100,200,300
```

输出各温度下 k_FGR/k_Marcus (相同 λ) 与 Marcus–Levich–Jortner 的比值。加 `--cif 晶体.cif` 同时给出迁移率张量，
加 `--kmc` 用同样的速率做 KMC。KMC 命令中的对应选项为 `--rate fgr --modes …`。
